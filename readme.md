키              기능

R           선택 해제
H           핸드오버 상태 확인
S           시스템 통계
C           핸드오버 완료 (수동)

T           테스트용 듀얼 모드 활성화
Q           종료


🔄 듀얼 카메라 동작 과정

평상시: 싱글 카메라 모드 (30fps)
핸드오버 감지: 자동으로 듀얼 모드 활성화 (20fps)
Re-ID 진행: 좌측(현재) vs 우측(다음) 매칭
매칭 완료: 유사도 85% 이상 시 자동 전환
전환 완료: 다시 싱글 모드로 복귀 (30fps)

🎯 주요 특징

⚡ 성능 최적화: 듀얼 모드에서도 20fps 이상
👁️ 시각적 연속성: 핸드오버 과정 실시간 확인
🔍 매칭 검증: 육안으로 같은 차량인지 확인 가능
🤖 자동화: 높은 유사도 시 자동 전환
🛠️ 수동 제어: 필요시 사용자 개입 가능
